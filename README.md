# usbif

**Status: Phase 0 (spikes and architecture). This is a local pre-repository working tree — the `PyDevices/usbif` GitHub repository is created only on `APPROVE USBIF GATE 1`, and nothing here is published.**

`usbif` is the planned third PyDevices `*if` module: a native C module plus a portable provider package bringing modern USB device and host capability to MicroPython on Espressif silicon, with the same Python surface on the desktop.

The controlling documents live in the workspace anchor:

- `docs/usbif-vision.md` — background, USB education, hardware, and software landscape
- `docs/usbif-roadmap.md` — the roadmap and phased implementation plan

Working documents in this tree:

- [docs/phase0-findings.md](docs/phase0-findings.md) — Phase 0 spike findings and queued experiment procedures
- [docs/api-sketch.md](docs/api-sketch.md) — API sketch v0 (a Gate 1 deliverable, not a stable surface)
